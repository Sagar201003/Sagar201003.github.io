Suspicious Activity Recognition

YOLOv8 DeepSORT ST-GCN PyTorch
Live Demo GitHub Repo

Overview

In today's fast-paced security environments, traditional CCTV monitoring requires immense human effort and is prone to error. This project introduces a state-of-the-art skeleton-based surveillance system capable of identifying and classifying suspicious behaviors in real-time. By tracking human pose semantics instead of raw pixels, the model achieves high robustness against occlusion and lighting variations.

The core pipeline integrates three distinct phases: high-speed object detection to isolate individuals, tracking algorithms to maintain IDs across frames, and a spatial-temporal graph convolutional network to classify the sequence of movements into benign or suspicious categories.

Problem Statement

Security personnel often suffer from cognitive overload when monitoring multiple camera feeds simultaneously. Existing automated systems using optical flow or standard 2D convolutions struggle with changing environments, shadows, and varying clothing types. We needed a solution that focused strictly on biomechanical movements—the fundamental indicators of physical actions like fighting, running, or falling—regardless of the subject's appearance or background noise.

Approach & Architecture

The architecture was designed as a cascading pipeline to maximize frame rates on edge devices. First, YOLOv8 accurately extracts human bounding boxes. Next, DeepSORT assigns temporal IDs to track individuals. The bounding boxes are then fed into a pose estimation model (YOLOv8-Pose) to extract 17 keypoints per person. Finally, an ST-GCN (Spatial Temporal Graph Convolutional Network) analyzes the 3D geometry of these skeletons over a rolling window of frames.

Results & Metrics

The model was validated on a custom curated dataset comprising over 5,000 action sequences and tested in real-world simulated environments. It demonstrated significant improvements in both accuracy and inference latency compared to traditional 3D-CNN baselines.

Tech Stack Deep-Dive

PyTorch

Used as the primary deep learning framework for training the custom ST-GCN architecture due to its dynamic computational graph and extensive community support.

YOLOv8

Implemented for high-speed, state-of-the-art human detection and pose estimation. It offered the best trade-off between mAP and latency for real-time video streams.

DeepSORT

Handled multi-object tracking. By combining Kalman filtering with a deep association metric, it efficiently tracked identities even when individuals momentarily crossed paths.
